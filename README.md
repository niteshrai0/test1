# Nitesh Rai — Portfolio V2

A dependency-light static portfolio designed for GitHub Pages.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive visual system
- `script.js` — small interactions

## Before publishing
Replace these placeholders in `index.html`:
- `YOUR_EMAIL_HERE`
- `YOUR_LINKEDIN_URL`
- `YOUR_RESUME_URL`

## GitHub Pages
Copy these files into the repository root (or the configured Pages folder), commit, and push.

## Editorial note
The site deliberately distinguishes personal contribution from product/business scale. Internal or commercially sensitive metrics should only remain public if you are comfortable disclosing them.
